# fish-fight (moved)

**Fish Fight is now [NibbleNaut](https://github.com/NafeesMansoor/NibbleNaut)**, playable at
<https://nafeesmansoor.github.io/NibbleNaut/>.

This small repository only keeps the old address `https://nafeesmansoor.github.io/fish-fight/`
working: it forwards visitors to the new address, helps players with an old home-screen icon move
over (with their progress code), and retires the old offline copy (`sw.js`). Don't delete it while
players may still have the old address installed.
